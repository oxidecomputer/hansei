= Durin

A library for reading and writing illumos CTF debug information.

It is specialized for handling the needs of `dwarf2ctf` when converting Rust DWARF debug information.

== Quirks

On x86_64, the disciminant for Rust enums is an `i64` by default (it is permitted to be smaller), while CTF mandates
that all enums must be an `i32`. We use enumerators to define enum disciminant values, but in cases where that value
does not fit in an `i32`, we need a workaround. The awful hack used it to append the hex value of the actual
disciminant to the enumerator name, e.g., `MyEnum@@0x01234567DEADBEEF@@`, with the value held directly in the CTF
being truncated to an `i32`.
