= exegesis

_Exegesis_: critical interpretation of an impenetrable source text.

A library: the DWARF parsing layer (formerly the `felak` crate) and the
extraction that turns it into a bundle. Cross-platform, so bundles can be
produced wherever the debug build happens. The CLI over it is `hansei
bundle` (`extract`, `stats`, `dump`, and the `dump-dwarf` probe that
absorbed felak's old binary); this crate builds no binary of its own.

A bundle is a zstd-compressed, postcard-encoded description of a debug
binary's async runtime: type layouts, symbol join tables, and provenance,
keyed by v0 mangled names so `hansei` can interpret a separately-compiled
target binary. Its wire format is the `hansei-bundle` crate, which carries
no DWARF dependencies -- the read side depends on that, never on this.
