= exegesis

_Exegesis_: critical interpretation of an impenetrable source text.

This crate is both sides of the async debug bundle:

* *lib*: the DWARF parsing layer (formerly the `felak` crate) plus the
  bundle format -- schema, reader/writer, and validation. Cross-platform,
  so bundles can be produced wherever the debug build happens.
* *bin* (`exegesis`, behind the default `cli` feature): the extractor and
  inspection CLI. `dump-dwarf` absorbs felak's old binary; `extract`,
  `stats`, and `dump` operate on bundle files.

A bundle is a zstd-compressed, postcard-encoded description of a debug
binary's async runtime: type layouts, symbol join tables, and provenance,
keyed by v0 mangled names so `hansei` can interpret a separately-compiled
target binary. Consumers that only need the lib (e.g. `hansei` via `reify`)
should depend on it with `default-features = false`.
